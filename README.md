# Almas Foulad Iranian

Official corporate website for **Almas Foulad Iranian Company**, developed using modern web technologies including Next.js 16, React 19, TypeScript, and Tailwind CSS 4.

This project is designed to provide a fast, scalable, SEO-friendly, and production-ready platform for showcasing company information, products, articles, and communication channels.

---

## 🌐 Live Repository

GitHub Repository: https://github.com/frau-azadeh/folad-iranian

Live Demo: https://folad-iranian.vercel.app

---

## 🏢 About The Company

**Almas Foulad Iranian** is a steel and industrial materials company focused on delivering high-quality products and professional services in the steel industry.

## 🛠 Installation

Clone the repository:

```
    git clone https://github.com/frau-azadeh/folad-iranian.git

```

### Navigate to the project directory:

        cd folad-iranian

### Install dependencies:

        npm install

---

## 💻 Development

    Run the development server:

        npm run dev


    Open in browser:

        http://localhost:3000

## 📦 Production Build

    To create a production build:

        npm run build


    To start the production server:

        npm run start

## 🧹 Code Quality

    Lint the project:

        npm run lint

## Check formatting:

        npm run prettier:check


    Fix formatting:

        npm run prettier:fix
